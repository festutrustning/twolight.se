# Growth Experiment — TWOLIGHT ORGANIC DISCOVERY

## Experiment

**Namn:** TWOLIGHT ORGANIC DISCOVERY  
**Start:** Vid indexerbar PROD-launch  
**Varaktighet:** 90 dagar  
**Hypotes:** En fokuserad, visuellt stark knowledge property om ljusdesign kan fånga informational/inspirational search demand som Festutrustning och Skaneevent inte bör äga som primary intent — och därefter skapa relevant downstream demand.

## Tidiga signaler (prioritetsordning)

1. **Indexation** — alla MVP-sidor indexerade i GSC
2. **Relevant impressions** — queries matchar Twolight primary ownership
3. **Improving positions** — trend uppåt för target clusters
4. **Clicks** — organisk trafik
5. **Commercial handoff** — outbound clicks till sibling properties

## Viktigt

- Bedöm **inte** projektet primärt på klick under första veckorna
- Deklarera inte success/failure före meningsfull crawl och indexation
