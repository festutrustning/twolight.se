# Query Ownership Map — Twolight Ecosystem

> **Syfte:** Undvika keyword cannibalization mellan Twolight.se, Festutrustning.se och Skaneevent.se.
> **Senast uppdaterad:** 2026-08-19

## Principer

1. Varje property äger **primary search intent** för sina queries.
2. Twolight får nämna commercial begrepp naturligt men **byggs inte** för att ta primary ownership.
3. Inga sitewide footer-länkar med exact-match commercial anchors.
4. Cross-property länkar sker endast **kontextuellt** när destinationen hjälper användaren.

## Cannibalization Risk Matrix

| Scenario | Risk | Mitigation |
|----------|------|------------|
| Twolight skapar "hyra uplights"-sida | **HIGH** | Förbjudet — handoff till Festutrustning |
| Twolight skriver "eventteknik guide" | **HIGH** | Undvik — Skaneevent äger termen |
| Twolight: "ljussättning bröllop" | **LOW** | Primary Twolight — Festutrustning fokuserar rental |
| Twolight nämner "hyra" i CTA | **LOW** | Kontextuell handoff, inte primary targeting |
| Alla tre skriver om samma event-case | **MEDIUM** | Three-property content model — separata vinklar |
